This assignment contains implementations and explanations of important Artificial Intelligence concepts including:

* Minimax Algorithm

Implementation of the Minimax algorithm used in game-playing AI for decision making.

### Concepts:

* Maximizing Player

Simple heuristic-based search implementation.
